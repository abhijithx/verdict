How the verdict is reached

01

Dry Run

Compile-check and basic runtime validation via Piston sandbox.

02

Test Generation

AI generates edge-case test suites with expected stdin/stdout pairs.

03

Sandboxed Execution

Code runs against all test cases in an isolated Piston runtime.

04

Deterministic Score

6-signal weighted scoring: correctness, performance, optimization, quality, readability, docs.

About Verdict

                    
An integrated dual-module AI platform for programmers.

                


                

                    
Mission

                    

                        Verdict empowers developers at both stages of algorithm design: finding the best algorithmic approach before coding, and thoroughly verifying code correctness and complexity after implementation.
                    


                    
Key Principles

                    
    
                        
  •  Independent dual modules sharing robust backend microservices.
    • 
                        
  •  Verified code execution using real sandboxed execution.
    • 
                        
  •  Strict JSON structure validation with retry logic.
    •
